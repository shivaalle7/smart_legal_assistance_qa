# Smart Legal Assistance Q&A Application

## Overview
Smart Legal Assistance is an AI-powered application designed to help users explore legal questions through a conversational question-and-answer interface.

Built with Python, LangChain, Groq API, and Streamlit, the application demonstrates how generative AI can support legal information retrieval and natural-language responses.

## Features
- Natural-language legal question answering
- LLM integration using the Groq API
- LangChain-based application workflow
- Interactive Streamlit user interface
- Clear and accessible presentation of responses

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/smart-legal-assistance-qa.git
   cd smart-legal-assistance-qa
   ```

2. Create and activate a virtual environment.

   ```bash
   python -m venv .venv
   ```

   Windows PowerShell:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Configure your Groq API key using an environment variable or Streamlit secrets. Never hardcode the key in your source code.

5. Start the application:

   ```bash
   streamlit run app.py
   ```
